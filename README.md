# Кондитерская 🌸 — Telegram Mini App

Заказы, рецепты и техкарты, учёт доходов. Без сборки: чистый HTML/CSS/JS. Дизайн в нежно-розовых тонах (светлый и тёмный вариант выбираются по теме Telegram).

## Что умеет
- **Главная:** заказы на сегодня и ближайшие, предупреждение о просроченных, «сколько ждём оплаты» и прибыль за месяц, быстрые кнопки «Заказ / Рецепт / Расход».
- **Заказы:** клиент, контакты (кнопки «Позвонить» / «Написать»), дата и время, самовывоз или доставка с адресом, вес, порции, бисквит, начинка, дизайн, фото-референсы, надпись на торте, аллергии, заметки, статус. Группировка по дням (просрочено, сегодня, завтра, на этой неделе, позже), поиск, фильтры. Оплата частями с историей, расчёт стоимости по весу (цена за кг в настройках).
- **Рецепты и техкарты:** ингредиенты списком (количество и единицы), шаги, выход, время, срок хранения, себестоимость, заметки, файлы (фото, PDF, Word, Excel). Пересчёт порции ×0,5 / ×1,5 / ×2 / ×3 одним нажатием. Поиск по названию и ингредиентам, категории.
- **Доходы по месяцам:** прибыль и сравнение с прошлым месяцем, выручка, расходы, получено, ждём оплату, средний чек, всего кг, выручка по неделям, любимые начинки, расходы по категориям.
- Telegram WebApp SDK, тема Telegram, имя пользователя в шапке, кнопка «Назад», тактильный отклик.
- Резервная копия: экспорт/импорт JSON.

## Деплой на Vercel
1. Создайте репозиторий на GitHub и загрузите содержимое папки.
2. На vercel.com: **Add New → Project → Import**. Framework Preset: **Other**, Build Command и Output Directory оставьте пустыми.
3. После деплоя получите адрес `https://your-app.vercel.app` (нужен именно HTTPS).

Или через CLI: `npx vercel --prod` в этой папке.

## Подключение к боту
1. В [@BotFather](https://t.me/BotFather): `/newbot`, если бота ещё нет.
2. `/newapp` → выберите бота → название, описание и **URL с Vercel**; либо `/setmenubutton` → URL, тогда приложение откроется кнопкой меню в чате с ботом.

## Где хранятся данные
- **Рабочие данные** (заказы, рецепты, расходы, фото и файлы) лежат на устройстве, в памяти Telegram (IndexedDB). На сервер ничего не уходит.
- **☁️ Облако Telegram:** тексты (заказы, рецепты, расходы, настройки) автоматически копируются в облачное хранилище Telegram (`CloudStorage`, нужен Telegram с Bot API 6.9+). На новом телефоне или после переустановки приложение само предложит восстановить. Фото и файлы в облако не попадают (у облака Telegram жёсткий лимит), после восстановления в записях будет подсказка, какие файлы загрузить заново.
- **Просмотр файлов:** фото открываются на весь экран с увеличением, PDF отображается прямо в приложении (PDF.js лежит в папке `vendor/`). Word/Excel внутри Telegram открыть нельзя, их лучше загружать как PDF или фото.
- **Файл с полной копией** (⚙️ → «Скачать копию») зависит от версии Telegram и телефона, в некоторых версиях сохранение файлов из мини-приложений не работает.

Если понадобится хранить фото и файлы надёжно и открывать с нескольких устройств, добавляется серверная часть: Vercel Functions + база и файловое хранилище, плюс проверка `initData` на сервере.


## Дизайн
Стиль «дофаминовый»: оранжевый, кремовый, розовый, салатовый и голубой, волнистые формы, бегущая лента. Шрифт Unbounded (лицензия SIL OFL) лежит в папке `fonts/` и подключается локально, интернет для него не нужен.
